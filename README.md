# LUMIBION Art Biotechnologies

Англоязычный сайт о программе исследований почвенных микроорганизмов. Четыре страницы, статические иллюстрации и форма подготовки обращения.

## Запуск

Требуются Node.js 22.12+ и Python 3.

```sh
npm ci
npm run dev
```

Локальный адрес — http://127.0.0.1:4173/. Команда `npm run build` собирает сайт в `dist/`.

## Размещение

GitHub Pages собирает и публикует содержимое `dist/` после изменений в ветке `main`. Для своего хостинга достаточно скопировать файлы из `dist/` в каталог сайта с поддержкой `index.html` для вложенных страниц.

Форма скачивает текстовый файл в браузере посетителя. Посетитель сам отправляет его своему контакту в LUMIBION.

Шаблоны находятся в `src/`, а используемые иллюстрации, знак и фавикон — в `public/assets/`.
